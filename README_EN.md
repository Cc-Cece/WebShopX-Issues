**WebShopX** is a web-based store and player trading system for Paper / Purpur / Spigot / Folia Minecraft servers.

The Minecraft plugin handles in-game business logic and APIs, while the web frontend provides modern store, market, and administration interfaces for players and server operators.

> This repository provides basic project information and automated builds. For the complete feature overview, screenshots, and version updates, see the [Modrinth project page](https://modrinth.com/plugin/webshopx).

## Features

- **Official Store** — Product purchases, recycling, inventory, purchase limits, and dynamic pricing
- **Player Market** — Sell orders, buy orders, player shops, supply containers, and trade management
- **Auction System** — English / Dutch / Vickrey / Candle Auction
- **Economy & Payments** — ShopCoin / GameCoin, Vault, currency exchange, recharging, and refunds
- **Order Fulfillment** — Automatic delivery, `/ws claim`, in-game mailbox, and fallback handling
- **Web Admin Dashboard** — Product, order, market, user, economy, and permission management
- **Multi-Server Support** — MySQL / MariaDB + Redis
- **Web Deployment** — Embedded / External / Relay

For a more complete list of capabilities, see **[Modrinth](https://modrinth.com/plugin/webshopx)**.

## Quick Start

1. Download the build matching your Minecraft / Java environment from [Modrinth](https://modrinth.com/plugin/webshopx).
2. Place the JAR in your server's `plugins/` directory and start the server.
3. Follow the [Installation & Deployment Guide](https://docs.akihito.dpdns.org/webshopx/admin/install-deploy) to complete the initial setup.

For first-time use, we recommend reading:

**[WebShopX Quick Start](https://docs.akihito.dpdns.org/webshopx/player/quick-start)**
